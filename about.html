About this project

Independent preparation, stated plainly

NS Fellowship Prep is a free, static checklist for people preparing for the public Network School Fellowship application process. It organizes 20 practical preparation steps across the form, Zoom interview, in-person exam, and decision stages so an applicant can review the work under their control.

This project is not official, affiliated with, endorsed by, or sponsored by Network School or Balaji Srinivasan. It does not contain private exam material and does not guarantee admission.

Who maintains it

Adam Pang maintains NS Fellowship Prep through the public GitHub repository. The site identifies the project and maintainer in its public structured data without claiming that the project represents Network School.

How it works

The checklist runs entirely in the browser. Checked items are stored in local storage on the same device. There is no account, application submission, analytics tracker, advertising pixel, external embed, or backend database attached to the checklist.

What it cannot tell you

Completing these steps is a preparation aid, not an assessment of admission likelihood. Fellowship requirements and schedules can change, so applicants should confirm current details through Network School’s own published channels before acting.
