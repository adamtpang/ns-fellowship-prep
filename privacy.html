Privacy disclosure

The checklist stays in your browser

NS Fellowship Prep is a static site. The checklist code does not send checked items, application answers, contact details, or other personal information to the site operator. There is no account system, contact form, application submission, analytics tracker, advertising pixel, external embed, or backend database.

Local checklist storage

When you check an item, the page stores its identifier in your browser’s local storage under the key ns-fellowship-prep-v1. That state remains on the device and browser profile where you used the checklist. The Reset checklist button removes this saved state.

Cookies

The site’s own code does not set cookies. The initial page response is intended to set no application cookie, and no code on the page reads cookies.

Hosting request data

The primary site is hosted by Vercel and the preserved mirror is hosted by GitHub Pages. Like other hosting providers, they may process routine request metadata such as an IP address, user agent, requested path, status code, and timestamp for delivery, security, and operational logs under their own policies.

Outbound links

The About and Contact pages link to public GitHub pages. GitHub receives ordinary request information only if you choose to follow those links. Its own privacy terms apply after you leave this site.

Questions or corrections

Use the public options on the Contact page to suggest a correction. Because GitHub issues are public, do not post private application material or sensitive personal information.
