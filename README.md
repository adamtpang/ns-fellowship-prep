# ns-fellowship-prep

A free readiness checklist for the Network School Fellowship application:
online form, Zoom interview, in-person exam, decision.

## Why

~4,000 people apply per cohort for 128 spots. Most applicants lose ground
on things that are entirely in their control: a vague form, an unrehearsed
pitch, no plan for the in-person stage. This is a checklist, not a magic
key, built by someone who went through the process for the people applying
next.

Not official. Not affiliated with Network School or Balaji Srinivasan.
Structure is sourced from public information about the Fellowship process,
not from NS itself.

## Run it

Static, zero dependencies. Open `public/index.html` directly, or serve it:

```
npx serve public
```

Progress is saved in the browser's localStorage only. Nothing is sent
anywhere, there is no backend and no tracking.
